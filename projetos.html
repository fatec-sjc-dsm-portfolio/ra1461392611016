Projetos semestrais

Resumo das APIs desenvolvidas ao longo do curso

A API (Aprendizagem por Projetos Integrados), desenvolvida no escopo do CADI, é uma metodologia de ensino implantada na Fatec São José dos Campos desde o segundo semestre de 2019. Essa abordagem organiza projetos semestrais com finalidade acadêmica e prática, nos quais os estudantes desenvolvem soluções para demandas reais, frequentemente propostas por clientes externos ou parceiros institucionais

1º semestre - 2022.1

Codificados

Cliente: Cliente interno da FATEC, professor Fabrício Galende

Tema: Sistema de gestão de serviços de tecnologia da informação

Problema: Controlar solicitações de serviços de TI para usuários e técnicos.

Solução: Sistema web para abertura e avaliação de chamados, com Flask e MySQL.

Figma Python Flask MySQL Trello

Contribuição: Minha atuação concentrou-se principalmente na função de Product Owner, com responsabilidades relacionadas à organização do backlog, planejamento das sprints e distribuição das tarefas entre os integrantes da equipe. Essa experiência foi importante para desenvolver habilidades de liderança, comunicação, priorização de demandas e acompanhamento do progresso do projeto.

2º semestre - 2022.2

TheSeven

Cliente: Empresa de desenvolvimento de software Midall

Tema: Gerenciamento e identificação de associados no Diário Oficial do Estado de São Paulo

Problema: Identificar associados e gerenciar os registros com mais agilidade.

Solução: Sistema web com React, Node.js e MySQL, apoiado por um bot de web scraping em Python.

Figma JavaScript React Node.js Python MySQL

Contribuição: Minha atuação ocorreu principalmente como desenvolvedor, com foco na criação de um bot responsável por realizar o processo de web scraping no Diário Oficial. Esse bot fazia o download das páginas, convertia os conteúdos em arquivos PDF, agrupava as páginas em cadernos e armazenava no banco de dados MySQL os parágrafos em que os associados eram citados.

3º semestre - 2023.1

CopiloTTeam

Cliente: Empresa de desenvolvimento de software Pro4Tech

Tema: Gestão financeira e comercial com automatização de processos

Problema: Cadastro manual de títulos, endereços e relatórios financeiros.

Solução: Sistema com cadastro de clientes, títulos e parcelas, integrado à API dos Correios.

Figma TypeScript React Java Spring Boot MySQL

Contribuição: Minha atuação ocorreu como desenvolvedor, com foco principal no backend do sistema, utilizando Java e Spring Boot. Essa experiência ampliou meu contato com o desenvolvimento de aplicações mais estruturadas, regras de negócio, organização de camadas e integração entre frontend, backend e banco de dados

4º semestre - 2023.2

Vitality

Cliente: Empresa Tecsus.

Tema: Sistema de Coleta de Dados de Estações Meteorológicas.

Problema: Integração de dados de múltiplas estações meteorológicas em um único sistema.

Solução: Desenvolvimento de um sistema para coleta, processamento e visualização de dados meteorológicos em tempo real.

TypeScript React Testes

Contribuição: Minha atuação foi como desenvolvedor, com foco principal no auxílio à criação de testes e na realização de correções pontuais no sistema. Essa experiência contribuiu para meu desenvolvimento na identificação de falhas, validação de funcionalidades e melhoria da qualidade do software, além de reforçar a importância dos testes no processo de desenvolvimento de soluções confiáveis.

5º semestre - 2026.1

FromZero

Cliente: Empresa de desenvolvimento de software Xertica.ai

Tema: Precedentes Jurídicos e Petições

Problema: Demora na análise de precedentes jurídicos

Solução: PrecedentIA, sistema com IA Generativa para apoio à análise de precedentes jurídicos

Python Flask IA Generativa Web Scraping Busca Semântica

Contribuição: Minha atuação ocorreu como desenvolvedor, com foco nos serviços de web scraping e embedding. No serviço de scraping, contribuí para a coleta e armazenamento automático de precedentes jurídicos a partir de fontes públicas, disponibilizando esses dados em cache para consumo por outros serviços da plataforma. Essa atividade fortaleceu minha experiência com automação de coleta de dados, organização de informações jurídicas e integração entre serviços. Para o serviço de embeddings, ajudei no desenvolvimento do sistema em Python, responsável por transformar precedentes jurídicos e petições iniciais em vetores semânticos. Além disso, participei da etapa de reranking dos resultados utilizando Cross Encoder, o que contribuiu para meu desenvolvimento em aplicações de Inteligência Artificial, busca semântica, processamento de linguagem natural e construção de soluções voltadas a problemas reais de alta complexidade.
